## 核心命题

人类越用越好用，因为会学习、会沉淀、会睡觉整理记忆。Agent 为什么做不到？——顺着这条线，引出 Dreaming，再追问：Dreaming 补了哪一块，还差哪几块，Agent 真正的自我进化路还有多远？

---

## 文章骨架

### 一、开场：你期待的 Agent 是什么样的？

- 建立直觉：好用的工具应该越用越顺手（编辑器、搜索……）
- 核心矛盾：Agent 用的时间越长，积累的经验越多，但表现没有变好
- 顺带点出"变蠢"：记忆污染，有时候反而更差

### 二、问题在哪：Agent 的记忆是怎么工作的

- 记忆是增量写入的，没有人整理
- 时间一长：重复、矛盾、过时条目堆积
- 类比：从来没整理过的纸质笔记本

### 三、人类为什么越用越好用：REM 睡眠

- 人类同样面对信息过载问题
- 进化的答案：睡眠，尤其是 REM 阶段
- REM 做了什么：去噪、巩固重要记忆、抽象规律——不是存更多，是整理得更好

### 四、Dreaming：Anthropic 给 Agent 造了一场梦

- 背景：2026 年 5 月 Code with Claude 开发者大会
- 工作原理：异步后台任务，读取最多 100 个历史 Session + 现有 Memory Store
- 三件事：去重合并、更新过时信息、提炼跨 Session 宏观规律
- 设计亮点：输出全新 Memory Store，不破坏原件，开发者可审查
- 与 REM 对位：白天 Agent 干活积累原始记忆，晚上 Dreaming 整理成有用知识
- 数据锚点：Harvey 法律 AI 接入后任务完成率提升约 6 倍

### 五、Dreaming 解决了什么，还没解决什么

人类学习的三层：
- **第一层：做中学** — 每次交互积累经验（Agent 已有：Memory）
- **第二层：睡眠整理** — 把碎片变成规律（Dreaming 补了这一层）
- **第三层：代际传承** — 整理好的知识固化进"本能"，不需要每次重新读（fine-tuning / 权重更新）—— Agent 基本空白

关键洞察：Dreaming 整理出来的记忆还在"外置存储"里，每次调用还需要去读。真正的内化还没有发生。

### 六、结尾：这只是开始

- 不给结论，给开放性问题
- Dreaming 证明了：Agent 可以在不重训练模型的前提下，通过整理经验变得更好用
- 但从"会整理记忆"到"真正越用越好用"，还有多远？
- 结尾问题：什么叫 Agent 真正学到了什么？

## 背景资料

**Dreaming 核心技术事实：**
- 发布时间：2026 年 5 月，Code with Claude 开发者大会
- 所属平台：Anthropic Managed Agents
- 触发方式：自动（空闲时）、定时、手动
- 输入：现有 Memory Store + 最多 100 个历史 Session
- 输出：全新 Memory Store（原件不可变）
- 支持模型：Claude Opus 4.7、Sonnet 4.6
- 现状：Research Preview 阶段

**实际效果案例：**
- Harvey（法律 AI）：任务完成率提升约 6 倍
- Wisedocs（医疗文档）：审查速度提升 50%，错误捕获率提升 30%
- Netflix：分析构建日志，识别重复失败模式
