# 配图 Prompts — Dreaming: 你以为在给 Agent 加记忆，其实是在教它学会忘记

共 5 张配图，覆盖文章核心概念。风格参考：科技感、简洁、深色背景，适合技术博客。

---

## 01-memory-flood.png

**用于**：文章开篇 / 第一节「只写入，没有遗忘」

**场景描述**：一个 AI Agent 被越来越多的记忆碎片淹没的感觉。一个发光的机器人/圆形节点，被海量的文字卡片、便利贴、对话气泡向四面八方涌来包围，这些碎片颜色逐渐变暗、变旧、变得杂乱。整体氛围是信息过载带来的压迫感。

**Prompt（英文，适用于 Midjourney / DALL·E 3 / Flux）**:

```
A glowing AI agent core, represented as a luminous sphere or node, surrounded and overwhelmed by an endless flood of floating memory cards, chat bubbles, and text fragments. The fragments near the center are bright and recent, but further out they become faded, yellowed, and chaotic. The scene conveys information overload and drowning in memories. Dark background, cool blue and white light palette, soft glow, cinematic, editorial illustration style.
```

## 02-rem-sleep.png

**用于**：第二节「人类 REM 睡眠」

**场景描述**：一个人在睡觉，半透明的大脑轮廓浮现在其上方，内部有发光的神经网络在活跃工作。100 个小光点从大脑中飘散消失，只留下 20 个更亮、更清晰的光点形成有序的结构。象征 REM 睡眠的「主动筛选」——丢弃 80%，留下最重要的 20%。

**Prompt**:

```
A sleeping human figure, lying peacefully, with a translucent glowing brain silhouette floating above. Inside the brain, a neural network is active — 100 small dim light nodes are drifting away and fading into darkness, while 20 brighter, more vivid nodes remain and form a clean, structured constellation. The mood is quiet, biological, almost magical. Deep indigo and soft amber tones, dreamy atmosphere, scientific illustration meets poetic art, dark background.
```

## 03-dreaming-mechanism.png

**用于**：第三节「Dreaming 机制」/ 封面候选

**场景描述**：一个 Agent（圆形光核）在夜晚「入睡」，旁边有一个异步进程（用齿轮/流光表示）在后台默默运行。旧的、杂乱的 Memory Store（一堆凌乱的碎片堆）正在被处理，从另一侧流出的是一份整洁、有序、分层发光的新 Memory Store。整体感：夜间静默作业，自动整理，从混乱到有序。

**Prompt**:

```
An AI agent core glowing softly in a night scene, seemingly dormant. Beside it, a background process visualized as gentle flowing light streams and translucent gears quietly runs. On the left: a messy pile of fragmented memory shards, overlapping and chaotic. On the right: a clean, layered, glowing new memory store with organized structure. An elegant transformation from chaos to order happens in the middle. Dark blue night palette, soft neon accents (cyan and violet), minimal and technical aesthetic, cinematic composition.
```

## 04-memory-landscape.png

**用于**：第四节「记忆技术全景图」

**场景描述**：五种记忆方案的全景可视化。一条从左到右的轴线，代表「持久性」从低到高。从左到右依次排布五个标志性节点：In-context（气泡，轻盈透明）→ RAG（书本/搜索框图标）→ Memory Store（数据库圆柱）→ Dreaming（圆形光晕，中间高亮）→ Fine-tuning（芯片/权重矩阵）。每个节点风格不同，Dreaming 节点用特殊的发光效果强调它是「质量控制层」而非独立存储。

**Prompt**:

```
A horizontal technology landscape visualization showing five memory solutions for AI agents, arranged left to right by persistence level. From left to right: a translucent bubble labeled "In-context" (lightweight, temporary), a book with a search beam for "RAG", a classic database cylinder for "Memory Store", a luminous radiant circle for "Dreaming" (highlighted as the quality control layer, glowing distinctly), and a neural weight matrix chip for "Fine-tuning". Each node connected by a glowing rail. Dark background, tech-diagram meets editorial illustration, cool blue and cyan color scheme with warm amber accent on Dreaming node.
```

## 05-ship-of-theseus.png

**用于**：第五节「这还是同一个 Agent 吗」

**场景描述**：忒修斯之船的数字版本。一艘由发光代码/数据组成的船，漂浮在虚空中，部分船板（代码块）正在被新的发光模块替换，旧模块飘散在空中但还未消失。旁边有一条版本历史时间线（v1 → v2 → v3），暗示身份连续性与版本变迁。整体感哲学、沉思，美感强。

**Prompt**:

```
A digital Ship of Theseus: a glowing vessel constructed entirely of floating code fragments, data nodes, and light patterns, drifting in a dark void. Some panels of the ship are being replaced — old translucent code pieces drift away while new, brighter modules click into place. Alongside the ship, a faint vertical timeline shows version markers: v1, v2, v3... The mood is philosophical and contemplative, asking questions about identity and continuity. Deep space background, indigo and soft gold color palette, painterly with digital textures.
```

## 使用建议

- **封面**：优先考虑 `03-dreaming-mechanism.png`，构图最完整，视觉表达与文章核心一致
- **尺寸**：建议 1200×675（16:9）或 1200×630（OG 图规格）
- **工具推荐**：Midjourney v6、DALL·E 3、Flux Pro
- **风格补充词（可追加）**：`--ar 16:9 --style raw --v 6` (Midjourney) / `cinematic, editorial, 4k, detailed`
