## 我现在在做什么

### 从 Text2SQL 里重新认识“落地”

目前的实习工作与大模型应用有关，近期主要接触 Text2SQL。它的 Demo 很容易让人产生一种错觉：把数据库 Schema 和用户问题交给模型，再让模型生成 SQL，好像就已经完成了自然语言查数。

真正做下去以后，问题会变得具体很多：用户说的指标到底对应哪个字段？时间范围应该按自然月还是最近 30 天计算？一条 SQL 能够执行，是否意味着它真的理解了业务口径？如果结果为空，究竟是没有数据，还是字段、权限或筛选条件出了问题？

所以我最近花了不少时间思考评测样本、Schema 信息、错误类型和结果语义，而不只是比较模型生成 SQL 的表面准确率。对我来说，这段经历最重要的收获不是记住了某个框架，而是开始理解：**一个能演示的方案，和一个值得交给真实用户的系统，中间隔着完整的评测与反馈闭环。**

这也是我最近写 Harness Engineering、Loop Engineering 相关文章的原因。文章里有一些思考仍然来自学习和实践中的观察，并不意味着我已经把所有系统都做成了生产级方案。我更愿意把博客当成一个记录“我正在弄明白什么”的地方。

## 我走过的几条路

### 大模型应用与 Agent

我目前主要关注大模型应用中的几个问题：如何组织上下文，如何让模型安全地使用工具，如何处理长任务中的状态和记忆，以及如何用独立的评估器判断任务是否真的完成。

相比“再写一个更长的 Prompt”，我更感兴趣的是模型之外的那部分工程：数据从哪里来，反馈如何产生，失败以后怎样回退，系统又应该在什么时候主动停下来。

### 数据挖掘与算法竞赛

本科期间我接触比较多的是数据分析、机器学习和算法竞赛。竞赛训练了我处理脏数据、构造特征、验证假设和快速试错的能力，也让我意识到，代码能力和想法同样重要。

竞赛不一定等同于真实业务，但它保留了一种很好的训练方式：先把问题拆开，再用实验结果而不是直觉判断方案。现在做大模型应用时，我仍然会下意识地寻找数据集、基线、失败样本和可重复的评估方法。

### 多模态情感分析研究

研究生阶段的主要研究方向是多模态情感分析，关注文本、音频和视觉信息如何共同参与情感判断。相关工作形成了论文：

**Dual-Perspective Multimodal Sentiment Analysis with MoE Fusion: Representation Learning via Semantic Resonance and Divergence**，发表于 *ICASSP 2026*。[查看论文](https://ieeexplore.ieee.org/document/11462471)

科研训练和工程工作给我的感受不太一样。论文更强调在明确实验设置下验证一个方法，工程更强调面对不完整需求、脏数据和不稳定依赖时把事情持续推进下去。两种经历并不完全相同，但都要求对“为什么有效”这件事保持诚实。

## 我能做什么，以及还在补什么

我现在比较有把握的事情包括：

- 使用 Python 和常见数据工具完成数据处理、实验和问题分析；
- 设计大模型应用的实验流程，整理失败样本并构造评测思路；
- 阅读和实现与 LLM、Agent、多模态学习相关的方案；
- 在有限时间内完成竞赛或研究任务，并通过实验结果调整方向；
- 把学习过程中的问题写下来，尽量把模糊的概念拆成可讨论的工程问题。

我也有明确的能力边界。大规模模型训练、推理服务、算力集群运维和高性能系统优化，并不是我已经可以有把握写在简历上的成熟经历；这些方向我仍在学习和补齐。因此，这个页面不会把我没有真正做过的事情包装成“熟悉”或“具备丰富实践经验”。

我更希望别人通过这里的文章、代码和具体项目判断我，而不是通过几个看起来很厉害、但无法说明细节的技术名词判断我。
